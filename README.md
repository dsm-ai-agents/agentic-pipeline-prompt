# The 5-Line Agentic Pipeline Prompt

A one-page teaching guide by Data Science Masterminds for building Claude agent pipelines.

**Goal → CLAUDE.md → Agents → Approval gate → Local folder, no execution**

## What's inside
1. The framework, line by line
2. What CLAUDE.md is and why it matters
3. Three annotated sample prompts
4. Live prompt builder with copy button
5. Common mistakes and fixes
6. A prompt to recreate this page

## Run it
Static site, no build step. Open `index.html` in a browser or deploy the repo to Vercel.
